# Customer Segmentation Project

## Overview
This project segments customers based on demographics and purchasing behavior using K-Means Clustering.

## Features
- Customer clustering using Machine Learning
- Analysis of customer behavior
- Visualization of customer segments
- Export segmented customer data

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-Learn

## How to Run

1. Install dependencies
   pip install -r requirements.txt

2. Run the project
   python customer_segmentation.py

## Output
- Customer segments
- Cluster visualization
- Segmented customer CSV file
